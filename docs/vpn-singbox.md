# Переход с Happ на sing-box

Сейчас браузер скраперов (del-mir, баланс) ходит через Happ — VPN-программу
с окном на Windows-сервере. Если Happ выключен или завис, скрапер падает.

Новая схема: программа сама запускает `sing-box.exe` (VPN-клиент без окна)
перед задачей, которой нужен VPN, и выключает после. Сервер VPN — наш, из
vpnctl (`Optima/Програмки/vpn`), с отдельным доступом `cvetopt-server`.
Через туннель идёт только браузер скрапера; почта и Excel — напрямую.

Переход сделан так, чтобы на каждом шаге можно было остановиться, а откат —
одна строка в `.env`.

## Шаги

### На маке (готовим)

1. **Доступ на VPN-сервере.** В папке vpnctl:
   ```bash
   ./vpn добавь cvetopt-server
   python3 collect.py
   ```
   Отдельный доступ — чтобы его можно было отозвать (`./vpn убери …`), не
   трогая остальных.

2. **Конфиг для Windows.**
   ```bash
   python3 render_client.py --mode server --client cvetopt-server --out ~/Desktop/cvetopt-vpn/vpn/config.json
   ```
   Внутри: наши VLESS-узлы, группа «авто» (сама выбирает живой узел), прокси
   на `127.0.0.1:2080`. Ни TUN, ни выхода «напрямую» — если туннель не
   поднялся, браузер не уйдёт мимо него.

3. **Проверка на маке.**
   ```bash
   sing-box check -c ~/Desktop/cvetopt-vpn/vpn/config.json
   sing-box run -c ~/Desktop/cvetopt-vpn/vpn/config.json   # в другом окне:
   curl -x http://127.0.0.1:2080 https://api.ipify.org          # IP нашего VPN-сервера
   curl -x http://127.0.0.1:2080 -I https://www.del-mir.com/login
   ```

### На Windows-сервере (переходим)

4. **Обновить программу** кнопкой «🔄 Обновить программу». Пока в `.env`
   нет `VPN_SINGBOX`, всё работает как раньше, через Happ.

5. **Положить sing-box рядом, Happ не трогать.**
   - Папку `vpn` (на маке: `~/Desktop/cvetopt-vpn/vpn`) целиком скопировать в
     папку программы → `C:\Apps\cvetopt\vpn\sing-box.exe`. Папка `vpn/` в
     `.gitignore`: обновление программы её не трогает и в git ключ не уйдёт.
   - Внутри: `sing-box.exe` и `libcronet.dll` (sing-box 1.13.19 windows-amd64,
     https://github.com/SagerNet/sing-box/releases) и `config.json` из шага 2.
   - Права на папку: чтение только у учётки, под которой работает cvetopt.
   - Если Defender/SmartScreen придержал `sing-box.exe` — разблокировать
     (свойства файла → «Разблокировать»).
   - Порт 2080 у sing-box и 10809 у Happ друг другу не мешают.

6. **Проверка без переключения.** В `.env` пока ничего не меняем. В PowerShell:
   ```powershell
   cd C:\Apps\cvetopt\vpn
   .\sing-box.exe check -c config.json
   .\sing-box.exe run -c config.json      # в другом окне:
   curl.exe -x http://127.0.0.1:2080 https://api.ipify.org
   curl.exe -x http://127.0.0.1:2080 -I https://www.del-mir.com/login
   ```
   Остановить `Ctrl+C`. Если IP — нашего VPN-сервера и del-mir ответил,
   можно переключаться.

7. **Переключение** — одна строка в `.env`:
   ```
   VPN_SINGBOX=vpn
   ```
   Перезапустить программу. В «Настройки → Проверить программу» пункт
   «VPN sing-box поднимается» должен быть зелёным, «del-mir открывается» —
   тоже. Затем вручную запустить del-mir. В журнале задачи будут строки
   «VPN: запускаю sing-box…», «VPN: туннель работает, внешний IP …».

   **Откат:** удалить строку `VPN_SINGBOX`, перезапустить — снова Happ.

8. **Наблюдение.** Один-два вторника по расписанию. Happ всё это время
   установлен, но больше не нужен включённым.

9. **Уборка.** Выключить автозапуск Happ. Саму программу оставить ещё на
   месяц на случай отката, потом удалить и убрать `PLAYWRIGHT_PROXY` из `.env`.

## Если что-то не так

- **«VPN: sing-box не запустился»** — в сообщении хвост его лога; полный лог
  `data\state\sing-box.log`. Обычно: неверный путь в `VPN_SINGBOX`, нет
  `sing-box.exe`/`config.json`, Defender заблокировал файл.
- **«VPN: туннель не отвечает»** — sing-box запущен, но ни один узел не
  доступен. Проверить с мака `./vpn статус`; если доступ отозван или ключи
  менялись (`rotate_keys.py`) — повторить шаги 2 и 5 (новый `config.json`).
- **«порт 2080 занят»** — висит чужая программа или старый sing-box, который
  программа не узнала. `netstat -ano | findstr 2080` → PID → завершить.

## Что учтено в коде

- Две задачи одновременно используют один sing-box; выключает его последняя.
- PID пишется в `data\state\sing-box.pid`: если программа упала, при
  следующем старте старый sing-box убивается (только если это именно он).
- Скрапер стартует только после реального ответа через туннель, иначе —
  понятная ошибка, а не таймаут del-mir.
- Порталы с `use_proxy: false` (Biflorica) VPN не поднимают.
