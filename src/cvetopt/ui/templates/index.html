  1. Заполнить Auto_new.xls

    Перелёты из Biflorica и «Транспорт трак» с del-mir.

    Перед запуском: на сервере включён Happ. Он нужен для «Транспорт трак» с del-mir, Biflorica открывается и без него.

  2. Почта, Excel и перевод

    Забирает инвойсы Enigma из почты, прогоняет Auto1 до файла для склада и переводит Голландия_1 по словарю.

    Перед запуском: закройте Auto_new.xls, если он открыт.

  3. Перевести новые названия в словаре

    Новые названия программа дописала в конец Словарь.xls, колонка C у них пустая.

    В колонку B копируйте оригинал из Description, а не перевод. Сохраните и закройте словарь.

  4. Перевести инвойсы

    Переводит названия в файлах папок 1 и 2, добавляет длину к розам и прогоняет Auto1 до Sort.

  1. Создать шаблон на сегодня

    Копирует «шаблон» в «шаблон ДД.ММ.ГГГГ» в папке склада. Оригинал не меняется.

    Если шаблон на сегодня уже есть, программа его не перезапишет.

  2. Заполнить сетку

    При приёмке сотрудник вносит количества по длинам в шаблон на сегодня.

  3. Разобрать миксы

    Списывает розы Mix из Biflorica по шаблону и добавляет позиции со средней ценой.

    Один раз на файл. В папке Biflorica лежит один свежий отчёт BiFlorica.

  4. Отделить гипсофилу

    Рядом с отчётом Biflorica создаёт «… Роза.xlsx» и «… Гипсофила.xlsx». Полный отчёт остаётся.

  1. Скачать отчёты Biflorica

    Скачивает «Отчёт по сделкам» и сразу создаёт по нему файл Эквадора.

Проверка программы

Проверяет папки, словарь, почту, прокси и логику программы (перевод, словарь, миксы). Рабочие файлы не меняются: всё тестовое создаётся в data\selftest.

Сброс для тестирования

Пути в настройках выше не меняются — только реестры «уже скачано» и при желании файлы в папках.

Сохранённые значения будут использоваться по умолчанию после перезапуска. Отчёты Biflorica — в папку скачивания. Перед прогоном в архив уходят «лишние» xlsx; при скачивании нового отчёта старые BiFlorica-*.xlsx переносятся в архив. Архив по умолчанию: C:\Инвойсы склад\архив (настраивается выше). Эквадор: после кнопки «Biflorica + Эквадор» файл создаётся автоматически (ecuador_create.auto_after_biflorica: true). Отдельный шаг — в Отдельные шаги на вкладке Запуск. Подробное описание кнопок — на вкладке Инструкция.

Ниже — что делает каждая кнопка. Одновременно может идти только один прогон. Пока идёт прогон — остальные кнопки недоступны. Не закрывайте окно программы во время работы.

Основные кнопки (вкладка «Запуск»)

1. «Скачать отчёты (Biflorica + Эквадор)»

Цепочка для ветки Эквадор.

  • Входит на Biflorica и скачивает отчёты по сделкам за период из Настроек (возраст заказов, дни).
  • Сохраняет файлы BiFlorica-*.xlsx в папку скачивания Biflorica.
  • Старые отчёты уходят в архив.
  • Сразу после скачивания (если включено в config) создаёт файл Эквадор ….xlsm через Excel по шаблону.

Нужны: Windows + Excel, логин Biflorica в .env, пути шаблона/выгрузки Эквадора в Настройках.

2. «Заполнить Auto_new.xls (перелёты Biflorica + Транспорт трак del-mir)»

Заполняет лист «АВБ перелеты» в книге Auto_new.

  • Шаг 1: с баланса Biflorica пишет вес, AWB и стоимость перелёта (Эквадор / Колумбия).
  • Шаг 2 (только если шаг 1 успешен): с del-mir.com подтягивает «Транспорт трак» по AWB.
  • Перед сохранением делается резервная копия Auto_new.xls.bak.

Нужны: Excel (или xlwt), логины Biflorica и del-mir, путь к Auto_new в Настройках. Период del-mir — в Настройках.

3. «Голландия: почта → auto1 → перевод»

Полный цикл ветки Голландия (три шага подряд).

  • Шаг 1 — почта: скачивает вложения из писем Enigma (xls/xlsx) в папки почты из Настроек.
  • Шаг 2 — Auto1: в Excel на листе auto1 жмёт Scan → Import → Calculate → Sort → «для склада»; получается Голландия_1_*.xlsx / .xlsm.
  • Шаг 3 — перевод: переводит Description по Словарь.xls (колонка B → C), добавляет красный/зелёный квадрат в столбцах A–B.

Важно: папки почты в Настройках должны совпадать с тем, что ждёт Auto1 — обычно C:\Invoice\1 (инвойсы) и C:\Invoice\1\2 (файл цен). Нужны: Windows + Excel, IMAP в .env, словарь и папка склада в Настройках.

3a. «Переведено (папки 1+2 → ростовка → Auto1 до Sort)»

Эта кнопка — продолжение после почты и ручного перевода словаря. Не путать с «Перевод (только)» (тот работает с уже готовым Голландия_1_* на складе).

Когда нажимать

  1. Уже скачаны вложения с почты: в папке 1 лежит инвойс, в папке 2 — файл цен (обычно C:\Invoice\1 и C:\Invoice\1\2, пути — в Настройках).
  2. Программа раньше дописала в словарь новые английские названия (колонка B), а вы вручную заполнили русские переводы в колонке C.
  3. Файлы в папках 1 и 2 ещё с английскими Description — их нужно перевести и проставить ростовку у роз, затем прогнать Auto1 до Sort.

Что делает программа по шагам

  1. Папка 1 (инвойс). Берёт Excel из папки коротких имён. Находит колонку Description (обычно L) и колонку длины S1 (обычно T).
  2. Перевод в папке 1. По словарю (B → C) заменяет английские названия на русские прямо в ячейках Description (отдельный столбец не создаётся). Переводится только название целиком, точно как в словаре (длину вида 60cm программа при поиске не учитывает). Если такого названия в словаре нет, строка остаётся на английском целиком, а программа дописывает её в словарь в колонку B с пустой C.
  3. Ростовка в папке 1. Для каждой строки-розы (первый токен названия — R или Роза, например R Tr Bombastic → Роза Бомбастик) к названию через пробел добавляется длина из колонки T (там уже число без cm). Пример: Роза Бомбастик 70. Другие цветы (хризантемы, эустомы и т.д.) не трогает.
  4. Папка 2 (цены). Берёт Excel из папки длинных имён. Колонка названия — Description (обычно F), длина — S1 (обычно K, вида 70 Cm).
  5. Перевод в папке 2. То же по словарю: Description переводится на русский в тех же ячейках, чтобы названия совпадали с папкой 1.
  6. Ростовка в папке 2. Всем розам к названию в F добавляется число из K без суффикса cm/см. Пример: из 70 Cm → Роза Бомбастик 70.
  7. Auto_new.xls, лист auto1. Открывает книгу и по очереди жмёт макросы: Scan → Import invoice → Calculate → Sort. После Sort останавливается.
  8. Не делает: кнопку Group не нажимает; «для склада» (Export2) не запускает; файл Голландия_1_* и маркеры A–B на этом шаге не создаёт. Выгрузку на склад при необходимости сделайте отдельно (кнопка Auto1 полностью или вручную).

Что проверить после прогона

  • В папках 1 и 2 у роз в названии есть длина через пробел, у не-роз — нет.
  • Названия в обоих файлах на русском и согласованы.
  • В Auto_new на листе auto1 данные после Sort подтянулись уже с ростовкой в описании.
  • В логе прогона: перевод папок 1 и 2, число роз с ростовкой, затем «Auto1 до Sort завершён».

Нужны: Windows + Excel, пути папок 1/2 и словарь в Настройках, заполненная колонка C словаря, файл Auto_new.xls. На Mac перевод файлов папок 1/2 выполнится, Auto1 будет пропущен.

3b. «Шаблон → копия на сегодняшнюю дату»

Готовит пустую сетку на сегодня: сотрудник потом заполняет её вручную (перед кнопкой «Миксы: шаблон → Biflorica»).

Когда нажимать

  1. В папке «Инвойсы склад» (Настройки → «папка Голландия_1_*.xlsx», обычно C:\Инвойсы склад) лежит файл шаблон.xls / .xlsx / .xlsm.
  2. Файла с сегодняшней датой ещё нет (или старый уже убрали/переименовали).

Что делает программа

  1. Находит в корне папки склада файл с именем шаблон (регистр не важен).
  2. Копирует его (оригинал остаётся).
  3. Имя копии: шаблон ДД.ММ.ГГГГ + то же расширение, например шаблон 31.08.2026.xlsx.
  4. Если такой файл уже есть — ошибка, чтобы не затереть заполненную сетку.

Что дальше вручную

  • Открыть созданный файл и заполнить сетку Эквадор (количества по нужным длинам) — как на созвоне.
  • Затем «Миксы: шаблон → Biflorica», потом при необходимости «Гипсофила».

Это не шаблон Эквадора (Прием товара Эквадор-4.xlsm). Папка та же, что для выгрузки Голландия_1_* — поле в Настройках «Перевод, папка Голландия_1_*.xlsx».

3c. «Миксы: шаблон → Biflorica»

Разбирает общий Mix в Biflorica на позиции из заполненной сетки шаблона — по любой длине, для которой в шаблоне есть заполненная колонка (не только 50/60/70).

Когда нажимать

  1. В папке склада есть заполненный Шаблон ДД.ММ.ГГ / шаблон ДД.ММ.ГГГГ (после копии и ручного заполнения).
  2. В папке Biflorica лежит полный свежий BiFlorica-*.xlsx с розами Mix.

Что делает программа

  1. Читает итоги и заполненные строки таблицы Эквадор для всех длин, что в ней есть.
  2. В Biflorica набирает стебли сорта Mix этой длины, начиная с самых дорогих.
  3. Списывает взятое; добавляет N строк: дата сделки как у исходных Mix, плантация «-», сорт = англ. код из колонки C шаблона, цена = средневзвешенная, количество = из сетки.
  4. Меняет Biflorica на месте (сделайте копию, если нужна страховка).

3d. «Гипсофила: разделить Biflorica (Роза / Гипсофила)»

Вместо ручного открытия Гипсофила.xlsm и кнопки «Да»: программа сама режет свежий отчёт Biflorica по типу цветка.

Когда нажимать

  1. В папке Biflorica (Настройки → «Biflorica, папка на ПК», обычно C:\Invoice\3) лежит полный BiFlorica-….xlsx (после скачивания / после разбора миксов).
  2. Нужны отдельные файлы для склада: гипсофила отдельно, остальной ассортимент — вместе.

Что делает программа

  1. Берёт самый свежий полный отчёт (не «… Гипсофила» / «… Роза»).
  2. По колонке ТИП (C): строки с «Гипсофила» → <имя> Гипсофила.xlsx; всё остальное (роза, альстро, гвоздика…) → <имя> Роза.xlsx (имя историческое).
  3. Полный исходный файл не удаляет.

Макрос Excel Гипсофила.xlsm не запускается — та же логика разделения в Python. Если нужен именно макрос с диалогом — напишите, подключим отдельно.

Отдельные шаги (блок «без цепочки»)

Для повторного прогона одного куска, если полный цикл уже частично сделан.

«Скачать вложения из почты»

  • Только шаг 1 Голландии: IMAP → файлы в папки 1 и 2.
  • Auto1 и перевод не запускаются.

«Auto1: Scan → … → для склада»

  • Только Excel-макросы на листе auto1.
  • Инвойс уже должен лежать в C:\Invoice\1, цены — один файл в C:\Invoice\1\2.
  • Перевод Description после этого не делается (если нужен — кнопка «Перевод» или полный цикл).

«Перевод (только)»

  • Берёт уже готовый файл Голландия_1_* в папке склада и переводит Description.
  • Почта и Auto1 не запускаются.
  • Переводится только название целиком, точно как в словаре (длину вида 60cm программа при поиске не учитывает). Если перевода нет — строка остаётся на английском, а текст дописывается в словарь (колонка B, C пустая).

«Эквадор: создать файл (без Biflorica)»

  • Берёт последний уже скачанный BiFlorica-*.xlsx и делает Эквадор ….xlsm.
  • Скачивание с Biflorica не запускается.
  • Удобно, если отчёт уже есть, а файл Эквадора нужно пересоздать.

Другие кнопки

«🔄 Обновить программу»

  • Делает git pull, обновляет зависимости и перезапускает сервер.
  • Нельзя нажимать во время прогона.
  • Сама сборка cvetopt.exe этим не обновляется — exe собирается отдельно (build-cvetopt-exe.bat).

«Сохранить настройки»

  • Записывает периоды и пути (Biflorica, почта, Auto_new, словарь, Эквадор и т.д.) в файл настроек.
  • После перезапуска программы эти значения остаются.

«Проверить программу»

  • Проверяет сервер: папки из Настроек, словарь, Auto_new.xls, Excel, вход в почту, сайт Biflorica, прокси Happ и сайт del-mir через него. Только чтение — письма не помечаются прочитанными, Excel не запускается.
  • Проверяет логику программы (перевод, словарь, «Переведено», почта, миксы) на файлах, которые сама создаёт в data\selftest\run. Рабочие файлы не трогает.
  • Результат — список с зелёными ✓ и красными ✗; у красных написано, что сделать. Серый «–» — проверку нельзя выполнить на этой машине (например, не задан прокси).
  • Удобно запускать после обновления программы и если что-то «вдруг перестало работать».

«Сбросить для повторного скачивания»

  • Очищает реестры «уже скачано» (Biflorica / почта) и по желанию удаляет файлы в папках.
  • Пути в Настройках не меняются. Нужно только для тестов повторного скачивания.

Типичный порядок работы

  • Эквадор: кнопка 1 (Biflorica + Эквадор) → при необходимости кнопка 2 (Auto_new + del-mir).
  • Голландия (старый полный цикл): кнопка 3 (почта → auto1 → перевод склада).
  • Голландия (после словаря): почта уже скачана → заполнить колонку C в словаре → кнопка «Переведено» → при необходимости отдельно «для склада».
  • Сетка на сегодня: «Шаблон → копия…» → сотрудник заполняет → «Миксы…» → «Гипсофила…».
  • Разделить Biflorica: кнопка «Гипсофила…» → файлы «… Гипсофила.xlsx» и «… Роза.xlsx».
  • Если что-то упало на середине — откройте «Отдельные шаги» и добейте нужный кусок.

Если появилась ошибка

  • На странице прогона видны только понятные шаги и понятная причина ошибки с подсказкой, что проверить.
  • Полный технический лог пишется в файл data\logs\ГГГГ-ММ-ДД.log в папке программы — его достаточно прислать разработчику, если причина непонятна.
